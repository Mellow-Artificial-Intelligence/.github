# mellow

Mellow's public GitHub organization profile and brand assets.

The organization README lives in [profile/README.md](profile/README.md).

Brand artwork follows the [studio direction in Mellow site PR #47](https://github.com/Mellow-Artificial-Intelligence/mellow-ai-site/pull/47), at `ff556ba1f528c73155890a8634263a7b58028c3e`: warm paper, charcoal, lavender, sage, and continuous-line artwork. The banner uses outlined Lato and DM Sans lettering so it renders consistently on GitHub without external font requests. The asterisk matches the source favicon.
